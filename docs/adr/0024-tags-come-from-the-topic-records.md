# Tags come from the Topic records, and a Snooze by Tag is a Snooze of a set

> **Superseded by [ADR-0034](0034-tags-are-defined-in-the-config.md):** Tags are no longer whatever the Topic records hold. Only the Tags that the Config lists in `topics.tags` exist, each with an optional colour and display name, and the Sidebar shows them as Tag Marks. The Snooze-by-Tag, chip and Go to… rules below carry over unchanged into ADR-0034.
