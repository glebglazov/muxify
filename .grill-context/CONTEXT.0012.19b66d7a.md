+ Hint
  The key that Muxify shows on a Topic or Session card, a Window row, a Tab or the Terminal while the user holds a modifier alone, such as ⌃2. Pressing that key goes to what the Hint is on.
  avoid: badge, number, label, Notification (when you mean the key mark)
  under: Layout
